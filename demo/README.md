# Demo en Angular

Banco de pruebas de `age-calculation-library`. Consume la librería **desde el
código fuente** (`../src/index.ts`, mapeado en `tsconfig.json`), así que lo que
se ve en pantalla es siempre el estado actual de `src/`, sin pasos de
publicación intermedios.

```bash
npm install     # dentro de demo/
npm start       # http://localhost:4200
npm run build   # dist/demo/browser
```

Requiere Node ≥ 24.15 (lo exige el CLI de Angular 22).
